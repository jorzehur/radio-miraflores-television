# Reglas de Autenticación Custom
1. PROHIBIDO sugerir, instalar o migrar a `NextAuth` o `Auth.js`.
2. Mantén la autenticación personalizada existente. Las credenciales locales para validación son `admin@radiomiraflores.com` / `admin123`.
3. Toda API en `/app/api/admin/*` debe validar la sesión antes de operar.
