description: Regla de revisión y verificación antes de cerrar tareas
metadata:
  type: feedback
---

**Regla:** Cada cambio de código debe ser probado y verificado para asegurar que funciona correctamente antes de marcar la tarea como completada.
**Por qué:** Evita entregar código con errores que puedan romper la aplicación en producción.
**Cómo aplicar:** Ejecutar pruebas locales, revisar la UI manualmente y confirmar que la funcionalidad esperada está presente antes de cerrar la tarea.
