Este proyecto es una aplicación web desarrollada con **Next.js** que incluye un **panel de administración** para gestionar contenidos y configuraciones. El frontend está escrito en React/TypeScript y utiliza Prisma como capa de datos. El objetivo es mantener la página principal y el panel de administración integrados, con despliegues continuos y pruebas automatizadas.
